# Change Plans

Use `active/yyyy-mm-dd-topic.md` for multi-step, risky, cross-component, or delegated work. A plan records current execution state: objective, non-goals, acceptance criteria, tasks, owners, dependencies, advisory write scopes, checks, rollback, blockers, and handoff state.

Move a finished plan to `completed/` only when its execution record remains useful; otherwise delete it after the durable decision and current-state documentation are complete. Completed plans are not authority for current product behavior.
